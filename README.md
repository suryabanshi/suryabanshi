# ⚡ VaultFlow — The 24/7 Income Machine

> **Your multi-stream online income ecosystem. Always growing. Never sleeping.**

VaultFlow is a complete, production-ready online money generating platform built with Next.js 14, TypeScript, and Tailwind CSS. It powers **5 revenue streams simultaneously**, all compounding day by day into a powerful income brand.

---

| Stream | Monthly Potential | Mechanism |
|---|---|---|
| 🛒 **Digital Product Store** | $200–$5,000 | Instant-download ebooks, templates, courses |
| 💎 **Membership Tiers** | $500–$10,000 | Bronze → Platinum recurring subscriptions |
| 🔗 **Affiliate Network** | $300–$8,000 | 30–50% commission on all referrals |
| 🔧 **SaaS Micro-Tools** | $100–$3,000 | Subscription AI tools and calculators |

---

## 🚀 Pages

- `/` — Hero landing page with live counters, growth chart, testimonials
- `/store` — 12 digital products with search, category filters, cart
- `/membership` — 4-tier pricing with monthly/annual toggle
- `/affiliate` — Commission calculator, leaderboard, affiliate link manager
- `/tools` — Free income calculator, profit analyzer, email optimizer
- `/dashboard` — Live analytics with real-time revenue tracking
- `/blog` — Content hub with newsletter signup

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS with custom brand system
- **Charts**: Recharts
- **Brand**: VaultFlow — Purple `#7C3AED` + Gold `#F59E0B`
