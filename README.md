# Knowledge Extraction System

A centralized, AI-powered knowledge database that ingests your entire digital ecosystem — files, chats, cloud storage, notes, and more — and surfaces business opportunities, patterns, and actionable insights automatically.

## What It Does

```
Your Data (Drive, Notion, ChatGPT, files, GitHub, ...)
         ↓
  AI Extraction (Claude)
         ↓
  Structured Knowledge DB (Supabase + pgvector)
         ↓
  Opportunity Finder + Insight Engine
         ↓
  REST API + Automation (n8n / Zapier)
```

## System at a Glance

| Layer | Technology |
|-------|-----------|
| Database | Supabase (PostgreSQL + pgvector) |
| AI Processing | Claude claude-sonnet-4-6 |
| Semantic Search | OpenAI text-embedding-3-small |
| API | FastAPI |
| Automation | n8n + Zapier webhooks |
| Deployment | Docker Compose |

## Quick Start

```bash
git clone https://github.com/suryabanshi/suryabanshi
cd suryabanshi/knowledge-system

cp .env.example .env
# Add SUPABASE_URL, SUPABASE_SERVICE_KEY, ANTHROPIC_API_KEY

docker-compose up -d
curl http://localhost:8000/health
```

Full setup guide: [`knowledge-system/IMPLEMENTATION_GUIDE.md`](knowledge-system/IMPLEMENTATION_GUIDE.md)

## Data Sources Supported

- Google Drive (Docs, Sheets, PDFs)
- Dropbox
- Notion databases
- Local files (PDF, Word, Excel, Markdown, CSV, text)
- ChatGPT & Claude conversation exports
- GitHub READMEs, issues, gists
- Any source via webhook (Zapier / n8n)

## Key Features

- **Hash + semantic deduplication** — never processes the same content twice
- **Multi-layer auto-tagging** — topic, domain, priority, and status tags generated by AI
- **Opportunity scoring** — ranks by ROI = (monthly revenue × 12) / effort days
- **Focus area analysis** — shows what you think about most, revealing your real expertise
- **Timeline tracking** — how ideas evolved over time
- **Graph relationships** — connect ideas, projects, people, and opportunities
- **One-click action plans** — Claude generates a 7-step 30-day execution plan per opportunity
